# duckify.app — Entscheidungs- & Verhandlungsvorlage

**Für:** Agentur-Einstieg als Commercial Co-Founder / Growth Partner
**Stand:** Pre-Launch / Konzeptphase · Basis: Council-Verdikt
**Grundregel:** Kein Equity-Commitment, bevor zahlende Nachfrage bewiesen ist.

---

## Teil A — Validierung ZUERST (Gate vor jeder Unterschrift)

> Reihenfolge ist Pflicht. Schritt 2 startet nur, wenn Schritt 1 besteht.

### Schritt 1 — Produkt-Realitätscheck (diese Woche, 0 €)
- [ ] Selbst eine Business-Website **und** einen Shop bauen — **mit Stoppuhr**.
- [ ] **Pass-Kriterium:** funktionsfähig in < 30 Min, ohne Hänger, ohne Workarounds.
- [ ] Mobile-Ansicht, Checkout-Flow und Rechtstexte (Impressum/DSGVO/Cookie) real prüfen.
- **Fail = Stopp.** Die gesamte „30-Minuten"-Story trägt nicht. Keine Gratisarbeit investieren.

### Schritt 2 — Nachfrage-Test (2–3 Wochen, ~1.500–2.500 €)
- [ ] Eine Landingpage mit **echtem Preis** (z. B. 49 €/Monat) + klarem CTA „Jetzt starten".
- [ ] 800–1.500 € Ads (Google/Meta) auf DACH-KMU / Gründer:innen.
- [ ] CTA führt zu **Vorkasse / 1 €-Anzahlung / Kreditkarte-Hinterlegung** (Beta-Plätze).
- [ ] **Messgröße:** Zahlungsbereitschaft. **Reine E-Mail-Adressen zählen NICHT.**
- **Pass-Kriterium (vorab festlegen):** z. B. ≥ X echte Anzahlungen / CAC unter Zielwert.
- **Fail = kein Deal** — und sechsstellige Gratisarbeit gespart.

### Parallel — Due Diligence (vor Unterschrift, nicht danach)
- [ ] **Cap Table** (bestehende Gesellschafter, Optionen, Wandeldarlehen).
- [ ] **Schulden / Verbindlichkeiten** des Startups.
- [ ] **IP-Eigentum am Code** — gehört die Plattform wirklich der Gesellschaft? (Freelancer-/Dienstvertrags-Kette prüfen.)
- [ ] **Markenrechte** duckify (DACH + EU) frei und anmeldbar?
- [ ] **Warum gibt der Gründer JETZT 25–40 % ab?** (Liquiditätsdruck / Burnout / Mitgründer-Konflikt) — ehrliche Antwort einfordern.

## Teil B — Term-Sheet-Eckpunkte (nur falls Teil A besteht)

> Kernprinzip: **Umgekehrte Logik.** Wer den knappen Faktor liefert (Marke, Funnel, Vertrieb, Nachfrage), kauft ihn nicht teuer ein.

| Punkt | Vorschlag des Gründers | **Position der Agentur** |
|---|---|---|
| Pre-Money-Bewertung | 750k – 1 Mio € | **≤ 250k €** (reale Pre-Revenue-Basis; Code-Reproduktionskosten, nicht Wunschwert) |
| Anteil Agentur | Start 25 %, bis 40 % | **35–50 % von Beginn an** (nicht „hocharbeiten" an selbst erzeugten Meilensteinen) |
| Vergütung | reines Sweat Equity | Sweat Equity **+ kleiner Cash-Retainer vom Gründer** als dessen Skin-in-the-Game |
| Vesting | — | **4 Jahre, 1-Jahr-Cliff, BEIDSEITIG** |
| Founder-Lock | — | **Reverse-Vesting / Founder-Lock für Tech-Gründer** (sonst Anteil an verlassener Codebasis) |
| Meilensteine | „100 zahlende Kunden" | **an MRR koppeln** (z. B. 10k € MRR) — Kundenzahl ist manipulierbar |
| Verwässerungsschutz | — | **Anti-Dilution + Tag-along-Rechte** |
| Leistungsumfang | „kompletter Aufbau" | **schriftlicher, abgegrenzter Scope** (sonst „liefert mehr"-Endlosschleife) |
| Exit / Scheitern | — | **definierte Ausstiegs-/Rückabwicklungsmechanik**, falls Launch scheitert |
| Haftung | offen | Klärung **persönliche Haftung bei automatischen Rechtstexten** (Abmahnrisiko), AGB, Geschäftsführer-Rolle |

## Teil C — Die 3 Deal-Breaker (sofortiges Nein)

1. Gründer akzeptiert **weder realistische Bewertung noch echte Co-Founder-Vesting-Struktur**.
2. **Produkt besteht den 30-Minuten-Test nicht** oder Nachfrage-Test liefert null Zahlungsbereitschaft.
3. **IP / Cap Table unklar** oder Gründer verweigert Einblick.

> Strategische Alternative, falls der Gründer blockt: **selbst bauen oder eine White-Label-Engine lizenzieren und 100 % behalten** — der teure kommerzielle Teil kommt ohnehin von der Agentur.

---

## Teil D — Offene strategische Fragen (vor Skalierung klären)

- **Betreiber-DNA:** Kann die Agentur einen 24/7-SaaS führen (Support, Churn, Retention, Produkt-Roadmap) — nicht nur Projektgeschäft?
- **Opportunitätskosten:** Was kostet die gebundene Kapazität das eigene Kerngeschäft?
- **Markt-Timing:** KI-Website-Generatoren (Wix AI, Lovable u. a.) kommodifizieren „Website in Minuten" gerade — wo liegt der verteidigbare Vorteil?
- **Echter Wedge (laut Council größtes Upside):** Distribution über **Multiplikatoren** (Steuerberater, Gründerzentren, Banken, Kammern) + **DSGVO/Compliance als EU-Exportprodukt** — beides als Distributionsrechte im Vertrag verankern.
